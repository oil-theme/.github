# Oil

A visually appealing dark theme designed for clarity. Enhancing the coding experience with a well-thought-out color palette.

## Themes

Oil currently supports 4 applications. You can find them below:

### Developer tools

- [Cursor](https://github.com/oil-theme/cursor)
- [Visual Studio Code](https://github.com/oil-theme/visual-studio-code)

#### Terminal Emulators

- [Ghostty](https://ghostty.org/)
- [iTerm2](https://iterm2.com/)

### Productivity

- [Raycast](https://github.com/oil-theme/raycast)
- [Slack](https://github.com/oil-theme/slack)
